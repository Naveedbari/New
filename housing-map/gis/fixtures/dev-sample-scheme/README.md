# Development sample scheme: SYNTHETIC DATA

**This is not a real housing scheme.** Every coordinate is made up. The scheme is placed in the
ocean near 0°N 0°E ("Null Island") on purpose, so it cannot be mistaken for DHA Bahawalpur or any
real place.

- Generated by `gis/scripts/generate-dev-fixture.mjs`. Do not edit the files by hand. CI checks that
  they match the generator output.
- CRS: EPSG:4326, GeoJSON `[longitude, latitude]` order, 7 decimal places.
- Contents: 2 sectors (A, B), 4 blocks, 12 streets, 3 roads, 120 plots, 4 points of interest.
- Plot numbers restart in each sector ("A-1" and "B-1" both exist), so ambiguous search results can be tested (AC-03).
- The API loads it only in the `Development` environment.
